# Resume-Screening-System
Resume Screening System using NLP Techniques

This project is a Natural Language Processing based web application that automates resume screening by comparing resumes with job descriptions using TF-IDF vectorization and similarity scoring. The system helps in ranking candidates based on relevance and improves recruitment efficiency.

Tech Stack: Python, NLP, Scikit-learn, Streamlit
Live Demo: https://resumescreeningsystem.streamlit.app
